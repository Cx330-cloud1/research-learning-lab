# Research Learning Roadmap

## Goal
Build the mathematical, programming, machine-learning, NLP, LLM, and research foundations required for independent AI research.

## Phase 1 — Foundations
Mathematics: Linear Algebra, Calculus, Probability, Statistics, Optimization.
Programming: Python, NumPy, Pandas, PyTorch basics.

## Phase 2 — Machine Learning
Regression, classification, regularization, optimization, model evaluation, error analysis, and unsupervised learning.

## Phase 3 — Deep Learning
Neural networks, backpropagation, gradient descent, optimization, training, and PyTorch.

## Phase 4 — NLP
Word embeddings, RNNs, attention, Transformers, and language modeling.

## Phase 5 — LLM
Language modeling, prompting, fine-tuning, PEFT/LoRA, evaluation, and alignment.

## Phase 6 — Agents
Agent architecture, tool use, memory, planning, and agent evaluation.

## Phase 7 — Research Skills
Paper reading, research questions, experiment design, scientific statistics, and academic writing.

## Study Rule
Learn → concise notes → implement → test understanding → connect to research.

Courses should support research rather than replace it.
